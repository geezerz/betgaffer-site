2. How do you know we didn't change the card later?

Think of the receipt code as a seal on the day's card: change a single pick and the code no longer fits. The card and the code are on the page, not in a screenshot we chose.

3. How many picks is that number based on?

Every accuracy figure we show tells you how many picks it covers and which dates.

A high percentage from ten picks tells you very little. The same percentage from a few hundred picks tells you a lot more, so we never show a figure on its own, and under 100 picks we show the count, not a percentage. A pick that's void, or that we couldn't grade, isn't counted as right or wrong, and the page says so.

4. Can you see the bad months too?

Yes. The record runs month by month, back to August 2026.

The bad months sit on the same page as the good ones. If a run of results goes against us, you'll see it there, not hidden behind a best-ever number.

5. What happens when we get something wrong?

When we're wrong in public, we correct in public.

Never a delete.
